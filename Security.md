# Security Policy

## Reporting a Vulnerability

**Contribute Wing** is a practice/learning repository — it does not run any live application, server, or service, so the risk surface here is minimal. Still, if you spot something concerning (e.g. malicious code submitted in a contributor's file, a broken link that leads somewhere unsafe, or any other security-related issue), please report it responsibly.

### How to Report

- Open an [Issue](https://github.com/Syntrojex/Contribute-Wing/issues) describing the concern, **or**
- Contact the maintainer directly: **Muhammad Mustafa ([@Syntrojex](https://github.com/Syntrojex))**

Please avoid publicly disclosing sensitive details (like exploit steps) in a public issue if the concern is serious — reach out directly first.

## Scope

Since this repository only contains:
- Markdown files (profiles, README, guides)
- Small, simple code snippets in various languages

...there is no application logic, dependencies, or infrastructure to exploit. Reports are still welcome for anything that looks off (e.g. a contributor's code snippet containing something malicious).

## Response

Reports will be reviewed as soon as possible. Since this is a community learning project maintained in personal time, response times may vary, but all reports will be acknowledged.
